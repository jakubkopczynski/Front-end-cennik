# Strona kalkulatora cen z modułami i opisem funkcji.

## Uruchomienie

```bash
npm install
npm run build
```

Otwórz `index.html` w przeglądarce (wymaga zbudowanych plików w `dist/`).

Podczas pracy:

```bash
npm run watch
```

## Struktura

- `index.html` — struktura strony
- `assets/scss/` — style (SASS)
- `assets/js/` — logika kalkulatora i scroll-spy
- `assets/img/` — ikony i ilustracje modułów
- `dist/` — skompilowane CSS i JS
